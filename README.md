# Aide-mémoire Kubernetes

Page HTML autonome (police, CSS et script inclus) récapitulant les commandes et notions essentielles de Kubernetes.

## Utilisation

Ouvrir `kubernetes-cheatsheet.html` dans un navigateur. Chaque commande peut être copiée d'un clic.

Une version imprimable est aussi disponible : `kubernetes-cheatsheet.pdf` (mêmes couleurs et même structure).

## Mise à jour

Le fichier est un simple fichier HTML/CSS/JS sans dépendance de build : l'éditer directement suffit.
